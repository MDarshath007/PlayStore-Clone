Built a Google Play Store inspired web app using HTML, CSS, Bootstrap, and JavaScript 🚀
This project was tougher than I expected and came with a lot of debugging and refactoring.

Challenges I faced:

• CORS issues while fetching API data
• Search and category filters breaking the UI
• Problems with localStorage between pages
• Responsive layout issues on mobile
• Messy repetitive code that needed optimization

After several fixes and restructuring, I managed to build features like:

• Dynamic game data using FreeToGame API
• Search, category & platform filtering
• Responsive UI
• Individual game details page
• localStorage integration

The biggest thing I learned from this project was how important reusable functions and clean frontend structure are while building applications.
Still learning and building more projects 🚀
